Signature icons for the offer e-mails (`ops/tools/build-email-v4.py`). Lucide strokes in a soft-green
tile, 72px PNG for a 36px slot. Rendered from the `.html` files with headless Chrome
(`--default-background-color=00000000 --window-size=72,72 --screenshot`), then copied to the VPS:
`scp ic-*.png givyxvps:/opt/givyx/images/brand/givyx/` → https://images.givyx.com/brand/givyx/ic-phone.png etc.
