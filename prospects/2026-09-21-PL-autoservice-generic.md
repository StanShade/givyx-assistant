## Screening log

**Method (what worked for an agent today):**
1. **panoramafirm.pl** category listings fetched with curl (`/warsztaty_samochodowe/<miasto>`, `/mechanika_pojazdowa/<miasto>`, `/stacje_obsługi_i_warsztaty_samochodowe/<miasto>`, pages 1–5). The listing HTML carries name, street address, phone, `www` link and the e-mail (`data-popup-param-email`), so it is a bulk source of published e-mails. 79 city slugs scanned, **7 880 listing rows** parsed (six slugs — Ostrowiec Św., Dąbrowa G., Wodzisław Śl., Ruda Śl., Biała Podlaska, Mińsk Maz., Nowa Sól, Starogard Gd., Pruszcz Gd. — returned a generic 282-row feed instead of the city; the address filter dropped those).
2. Pre-filter in Python: e-mail present **and** mobile prefix **and** `www` empty / Facebook / free subdomain **and** address in the queried city **and** name not tyre/body/LPG/towing/electrics/parts/truck/detailing-led → **251 candidates**.
3. **Google Maps place page** in the Claude Browser pane for each candidate opened (`maps/search/<name> <street> <city>`, then a JS read of h1, star histogram aria-labels, `a[data-item-id="authority"]` href, phone and address). **84 Maps look-ups run** → 42 qualified, 42 dropped (not on Maps at that name/address 17 · has an own-domain website 12 · wrong shape on Maps: LPG, scrapyard, tyres, TIR, medical lab, welding shop 6 · rating ≤ 3,9 or phone differs 7).
4. Facebook "About" tabs logged-out in the pane work (e-mail + mobile visible; test on facebook.com/KitaTronic/about) but yield was 0/6 e-mails on the first six Tarnów FB-only pages found via WebSearch (`site:facebook.com warsztat samochodowy Tarnów`), so the FB route was dropped in favour of the directory route. `/p/<name>-<id>/about` URLs redirect to meta.com — use `facebook.com/<id>/about` instead.
5. Dedup: every surname / brand grepped across `prospects/` before the Maps check.

**Sources that did NOT work:** Facebook via curl (HTTP 400 on every page URL) · Google Maps via curl (the search page ships no results; they load by XHR) · aleo.com and cylex.pl (403 to curl) · pkt.pl search returned a 12 KB shell with no listings. Bing/DDG were not tried (runbook: captchas).
