# Reference: the original skill definition

This folder holds `original-skill-definition.md` - an anonymised version of how the SEO Article Writer is assembled and works as an AI-agent skill in real operation.

**Why you need it.** The main product (methodology + Autopilot + tools) gives you the process. This file shows the **mechanics of the skill**: how it triggers on phrases, how it behaves in autonomous mode, on which 5 gate conditions it stops, what it reads at start. Useful if you want not just to walk the methodology by hand, but to build from it a permanent skill for your own agent that starts on one phrase and takes the article through to publication itself.

**It is not a duplicate of the root `SKILL.md`.** The root `SKILL.md` is the live manifest for installation (short, picked up by Claude Code). This file is the extended definition with the philosophy, the boundary conditions and the map of the 16 stages: a reference and proof that behind the product stands a field-tested process, not theory.

The content is anonymised: everything specific to a particular project has been moved into `config.yaml`, as everywhere in the product.
